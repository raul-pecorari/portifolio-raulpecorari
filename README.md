# Portfólio — Mirian Guerra

Portfólio estático com 8 demos de sites comerciais.

## Estrutura

- `index.html` — página principal do portfólio
- `css/style.css` — estilos do portfólio
- `js/script.js` — filtros e animações
- `sites/` — 8 sites demonstrativos

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todo o conteúdo desta pasta para a branch `main`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

## Antes de divulgar

Troque o e-mail de exemplo em `index.html` por seu e-mail/WhatsApp real.
